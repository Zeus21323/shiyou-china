# 诗游中国

全国三维行政区划示意 → 浙江省 4A/5A 历史名录 → 景区诗文星云 → 原文与关联依据。

## 当前范围

- 网站现展示山水古迹精选 178 个景区（20 个 5A、158 个 4A），其中 103 个有高德点位。按用户要求剔除 67 个现代展馆、科普设施、动物园、主题乐园、影视基地及商业度假设施；名单及类别见 `lib/scenic-selection.ts`，地图、名录、搜索及数量统一筛选。全部 10 个诗文目的地和 18 篇作品保留。以下 245 条名录及 131 个点位是原始数据底册数量，不是当前网页展示数量。

- 全国 34 个具名省级地区可选择，支持列表选择小面积地区。
- 浙江名录截至 2024-12-31：22 家 5A、223 家 4A。来源为浙江省文化广电和旅游厅 2025-01-21 发布的名录；不是实时等级。
- 首批 10 个景区、18 篇作品（17 首诗、1 篇文言文）。每个亮星对应一篇真实作品，背景微尘仅为装饰。
- 未收录作品的景区显示空状态；其他省份没有虚构景区数据。
- 卷轴青绿风格：全国省份标签、点击下钻、5A 优先、放大逐步显示 4A、近邻聚合与标签避让。山形为程序生成的艺术示意，非真实高程。
- 高德 Web 服务点位 131/245（22 个 5A 全覆盖、109 个 4A，包含全部 10 个诗文目的地）；114 个待消歧，仍可从名录访问。联合景区用代表点。

## 维护与执行步骤

1. **更新景区底册**：保存官方名录与公告原件、发布日期、适用日期；对照旧数据记录升级、降级、撤销和更名。保留稳定 ID，不能以行号重新生成已有景区的 ID。
2. **补充地理位置**：在本地忽略文件 `.env.local` 配置 `AMAP_WEB_SERVICE_KEY`，运行 `npm run data:geocode`。密钥仅由离线维护脚本使用，不进入网页。脚本保留本地查询缓存，按名称、市和区县核对，歧义项写入 `work/amap-review.json`；已查看的别名/代表点在脚本中逐项记录。需要更新官方结果时先备份并移走 `work/amap-query-cache.json`。GCJ-02 原坐标与近似转换的 WGS84 一同保留；不得把市中心作为未确认景区位置。
3. **建立作品库**：从许可明确的电子古籍/语料导入题目、作者、朝代、体裁、原文、文本版本、来源和记录位置；按作者/题目/正文去重，不合并异文。
4. **建立关联表**：作品与景区应最终拆为多对多关系。记录古地名、现代地名、直接描写/游历/题咏类型、对应的具体景点及证据。当前首期作品各挂接一个景区，数据接口需在扩展时迁移。
5. **审核后发布**：关键词及 AI 只能生成候选；按题目、正文、地方志或官方文物资料逐条核对。保留审核状态，疑似同名地点和有乱码原文不得自动发布。当前为 AI 辅助逐条核对，尚非专家校勘。
6. **迭代交互**：逐省引入官方名录和核验坐标；加入景区点位聚合、朝代/作者筛选前先确认使用场景。全国作品量增加后按省/景区延迟加载，保持手机列表阅读方式。
7. **验收与上线**：运行数据对照、类型检查、生产构建；验证省份选择、筛选、星云点击、原文出处、返回和空状态。公开发行前完成地图许可/地图发布要求核验，并复核名录变化。

## 开发

Node >= 22.13。执行 `npm ci`、`npm run dev`；生产构建 `npm run build`。使用 React、TypeScript、Three.js、React Three Fiber、vinext 与 Sites。

执行 `npm run test:map` 验证密集标签避让、聚合、放大分离及点位来源完整性。点位取自高德 POI，不是实时导航或开放状态服务。

## 数据来源与限制

完整来源见 `public/data/sources.json`；作品证据见 `public/data/works.json`。

- [浙江官方名录](https://ct.zj.gov.cn/art/2025/1/21/art_1229678763_5447295.html)
- [Werneror/Poetry](https://github.com/Werneror/Poetry)，许可证保存在 `public/licenses/Poetry-MIT.txt`。
- [兰亭集序原文](https://www.guwendao.net/shiwenv_af279f0cdd95.aspx)，只使用古典原文。
- [江心屿地理关联依据](https://wwj.zj.gov.cn/art/2024/6/6/art_1641242_59060914.html)
- [地图数据](https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json)，仅作行政区划示意，未完成公开地图发布要求与使用许可核验。

首期采用静态 JSON，无账号、付费、用户上传和持久化收藏。原文核对不等于学术校勘，不能以现代评级边界推断古代创作地点。
