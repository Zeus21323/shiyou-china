# 莲花灯模型

本地来源：项目根目录 `莲花灯/lotus-lantern.glb`，由用户指定导入。
`lotus-lantern-lite.glb` 来自同一目录，为相同造型的轻量版本。
两个文件均按原始字节复制；纹理内嵌，不依赖外部模型网站。

主场景选中的灯使用完整版，周围灯群使用轻量版；通过 GPU 实例化共享网格与材质。
开合采样各自 GLB 的 `Bloom` 动画，保留 28 片花瓣原有形态和分层节奏。
熄灭灯隐藏火焰并降低实例颜色；点击检测使用每个实例的实际形变。
单灯检查页 `/lotus-inspection` 使用完整版，可切换开度和观察角度。

更新资产时请同时复制同一版的完整与轻量 GLB，再运行 `npm run test:map` 和 `npm run build`。
